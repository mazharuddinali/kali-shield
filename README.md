# Kali Shield

Kali Shield is a cybersecurity toolkit built on Kali Linux designed to enhance system security and help users practice defensive security techniques.

## Features
- Network scanning
- Port scanning
- Security automation
- USB device blocking for protection against unauthorized devices
- Simple command-line interface

## How USB Blocking Works
Kali Shield helps prevent unauthorized USB devices from connecting to the system. This can protect against threats such as:
- Malware delivered through USB drives
- Data theft through external storage
- Unauthorized device access

## Installation

Clone the repository:

git clone https://github.com/mazharuddinali/kali-shield.git

Navigate to the project folder:

cd kali-shield

Run the tool:

python3 app.py
